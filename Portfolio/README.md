# Coded Future — Frontend Developer Portfolio

A modern, responsive frontend developer portfolio built with:
- HTML5
- CSS3
- Vanilla JavaScript
- Font Awesome
- Google Fonts

## Features
- Responsive mobile navigation
- Dark/light theme toggle
- Page loading animation
- Scroll reveal animations
- Project category filtering
- Active navigation link on scroll
- Responsive skills, projects, services and contact sections
- No framework required

## Run
Open `index.html` in your browser.

## Customize
Replace the `#` social links, update project details, and change `hello@example.com` in `index.html`.
